# Calculator Project

A simple modular calculator written in C.  
This project demonstrates tokenization, parsing, and evaluation of mathematical expressions using stacks.

## Features
- Supports basic arithmetic: `+`, `-`, `*`, `/`, `%`
- Supports exponentiation: `^`
- Handles parentheses for precedence
- Supports negative numbers (unary minus)
- Supports floating point numbers (e.g. `2.5 + 3.7`)
- Modular design: separate files for tokenization, stack operations, evaluation, and main program
